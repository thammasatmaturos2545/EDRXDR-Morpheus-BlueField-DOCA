# Dashboard demo — 16 October 2026

## Scope

New overview at `/`; Endpoint results at `/shadow`; BlueField evidence at `/bluefield`; original detailed dashboard at `/details`. Existing APIs, models, contracts and data are unchanged. Counts come from the existing APIs. Failed reads display unavailable values, not invented zeros. No background polling.

The new runner points Shadow, Replay and BlueField history to the existing replay OpenSearch container. Other original detailed-dashboard APIs retain their existing configuration. System status describes the host running Next.js. Do not describe it as end-to-end data flow health.

## Speaking sequence — approximately 4 minutes

1. **Overview, 30 seconds.** Explain the two evidence streams: Endpoint model results and network telemetry. These are stored experimental results, not continuous live detection.
2. **Shadow, 60 seconds.** Show the current counts and one event's source occurrence plus matching raw hashes. Matching proves correspondence of inputs, not model accuracy. Candidates are disagreements against weak labels and still need review. No AE score does not mean safe.
3. **BlueField, 60 seconds.** Show current Shadow records and expand a record. Explain unknown carrier versus measured zero and first-sample delta. Historical and Shadow views may describe the same archived six records; do not add them as separate samples. This does not prove active live sampling or packet inspection.
4. **Model quality, 45 seconds.** Open `/details#quality`. Quote only metrics and scope actually returned by the real report. If unavailable, state that it is unavailable. Development results are not production performance.
5. **Next work, 30 seconds.** Operator step8 has 123 reported tests and deployment preflight evidence, with replay_authorized=false and production_ready=false. No production claim. BlueField publisher remains stopped/disabled pending validated integration.
